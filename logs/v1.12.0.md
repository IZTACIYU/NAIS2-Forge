# v1.12.0 개발 로그

## 이미지 공유 카드

- 메인 탭 프롬프트 패널의 `조각`·LLM API 버튼 사이에 `이 프리셋의 프롬프트 공유` 버튼을 추가했다. 카드 값은 버튼을 누를 때 표시된 이미지의 생성 메타데이터에서 가져오며, 원본 이미지는 카드에 싣지 않는다. 세로형 카드에 모델·모드, 최종 생성 프롬프트, 네거티브, 스텝, CFG, 샘플러, 스케줄러, 품질/UC 프리셋을 정렬한다.
- 카드의 항목명은 연한 로열골드색 굵은 글씨, 값은 밝은 글씨로 표시하며 개별 박스형 컨테이너를 사용하지 않는다. 프롬프트 전문은 길이에 맞춰 카드 높이가 늘어난다.
- 원본 이미지의 공식 NovelAI `Comment`·`Source` 등 생성 메타데이터와 기존 Forge `nais2-params`를 새 카드 PNG에도 기록한다. 현재 화면의 설정값을 원본 메타데이터 대신 사용하지 않으며, 원본 이미지나 사용자 저장 데이터는 변경하지 않는다. 메타데이터가 없는 이미지로는 호환 가능한 카드를 만들 수 없으므로 저장을 막는다.
- 새 기능에 따라 개발 대상 버전은 v1.12.0이다. 실제 앱 버전은 릴리즈 요청 전까지 v1.11.0을 유지한다.
- 카드 화면에서 PNG 다운로드, PNG 클립보드 복사, 독립 HTML 코드 복사를 제공한다. 화면의 각 값 옆 복사 버튼은 그 값만 복사하며, HTML 코드에도 항목별 복사 버튼을 포함한다.
