# v1.14.1 개발 로그

## 그림체 프리셋 초기화 결함 수정

- 앱 시작이나 새로고침 중 기존 그림체 프리셋 목록이 기본 프리셋 하나로 덮어써질 수 있던 결함을 수정했다. 초기 함수 등록 자체가 저장을 발생시키던 경로를 제거하고, 생성 설정과 프리셋이 모두 로드되기 전에는 자동 동기화가 저장을 예약하거나 실행하지 않게 했다. 프리셋 전환·편집 후 자동 저장과 기존 지연 시간은 유지한다.
- 사용자 지시 범위는 다음 업데이트에서의 재발 방지다. 기존 저장 키·DB/backend·schema·직렬화·hydration 기본값·migration은 변경하지 않는다. 프리셋 ID·순서·프롬프트·설정·선택과 추가 필드를 보존하며 초기 로딩만으로 프리셋을 다시 저장하지 않는다. 설치판의 실제 DB를 열거나 수정·복구하지 않았으며, 이미 덮어써진 목록 복구는 별도 세션에서 진행한다.
- 격리된 비동기 저장소에서 실제 프리셋·생성 store와 Zustand middleware를 실행해 검증했다. 양쪽 로드 순서, 저장소 재생성을 통한 반복 새로고침 상황, 6개 전체 레코드와 알 수 없는 필드 보존, 프리셋 전환·편집 동기화, 로드 중 예약된 저장 및 읽기 실패의 덮어쓰기 차단을 통과했다. 통과 검사를 반복하거나 설치판 재시작·전체 저장 키·조각·이미지 전수 검사를 하지 않았다.
- production build와 관련 회귀 검사는 각 1회 통과했다. lint는 1회 실행했으나 기존 ESLint 설정 파일 누락으로 실패했다. 씬 이동 시 깜빡임 자체의 원인은 확인하지 않았고 이번 결함과 같다고 단정하지 않는다.
- 실제 앱 버전은 1.14.0으로 유지한다. 릴리즈·태그·워크플로 실행은 진행하지 않았다. 저장 형식 변경이나 데이터 migration이 없어 새 버전을 위한 변환/정리 작업은 필요하지 않으며, 구버전에는 같은 초기화 결함이 남아 있으므로 단순 다운그레이드를 데이터 보존책으로 보지 않는다.
