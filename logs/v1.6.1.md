## 데이터 호환성

### 모델별 생성 옵션 기억

- 승인: 2026-08-25 사용자 승인 후 진행.
- V5와 V4.5 등 모델을 전환할 때 UC Preset, Quality Tags, Mode, 투명 배경, Variety, SMEA 선택이 다른 모델로 이어지지 않고 각 모델의 마지막 선택을 복원하도록 변경했다.
- 기존 `nais2-forge-generation` 키와 기존 필드는 유지하고, 비활성 모델의 선택만 담는 `modelOptionMemory`를 선택적 필드로 추가했다. 현재 활성 모델의 기존 값은 그대로 보존하며 처음 방문하는 모델은 해당 모델의 기본값을 사용한다.
- 기존 생성 프리셋과 메타데이터 임포트는 기존 generation store 액션을 통해 대상 모델 값만 갱신한다. 이전 버전으로 롤백하면 새 필드는 무시되며 기존 필드는 유지된다.
