# NAIS2-Forge v1.9.0 개발 로그

## 주요 변경

### NovelAI 다중 계정 토큰

API 설정에서 NovelAI 토큰 입력칸을 여러 개 추가하고, 각 토큰을 검증해 현재 생성에 사용할 계정으로 전환할 수 있도록 추가.

- 마지막으로 검증에 성공한 토큰이 현재 활성 토큰이 되며, 자동 순환이나 임의 계정 전환은 하지 않는다.
- 승인: 2026-08-30 사용자 승인.
- 저장 변경: 기존 `nais2-forge-auth`의 단일 활성 `token`은 그대로 유지하고, 검증된 추가 토큰 목록인 선택적 `tokens` 필드만 더한다. 저장 키와 기존 토큰 값은 변경하거나 이동하지 않는다.
- 호환성/복원: 이전 설치에서 목록 필드가 없으면 기존 단일 토큰을 첫 입력칸으로 그대로 사용한다. 별도 migration이나 기존 데이터 재작성은 없으며, 이전 코드로 되돌려도 기존 `token` 필드를 계속 읽을 수 있다.
