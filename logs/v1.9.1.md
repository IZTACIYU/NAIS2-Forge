- 더 이상 사용하지 않는 Discord·Marketplace·Supabase 흔적 제거

### 앱 식별자 및 데이터 경로 변경

- 승인: 2026-08-31 사용자 승인
- 정식 앱 식별자를 `com.iztaciyu.nais2forge`로 변경
- 기존 설치의 Roaming·Local 앱 데이터는 새 WebView가 생성되기 전에 임시 경로로 전체 복사하고, 파일 크기와 SHA-256을 검증한 뒤 새 경로로 전환
- 기존 경로는 삭제하거나 수정하지 않으며, 새 경로에 이미 별도 데이터가 있거나 복사·검증이 실패하면 빈 데이터로 앱을 시작하지 않고 migration을 중단
- 첫 실행에는 기존 앱 데이터 용량만큼의 추가 디스크 공간과 복사·검증 시간이 필요하며, 자동 원본 정리는 수행하지 않음
- 구버전으로 되돌리면 migration 당시 보존한 기존 경로를 다시 사용할 수 있으나, 변경 후 새 경로에만 저장된 데이터는 구버전에 자동 반영되지 않음
