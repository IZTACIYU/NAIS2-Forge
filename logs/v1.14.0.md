# v1.14.0 개발 로그

## 조건 문법 자동완성 및 다중 삭제

- `#if+`·`#if-`의 조건과 `#del-`의 삭제 대상을 입력할 때 명령어 부분을 제외한 현재 태그로 자동완성 검색을 수행한다. 선택 시 명령어·앞선 조건·구분자는 보존하고 현재 태그만 교체한다. 조건의 `&`·`/` 연결 및 `:` 뒤 본문, 줄 중간 편집도 구분한다. 조건 선택에 일반 프롬프트용 쉼표를 강제로 붙이지 않는다.
- `#del-blue eyes, red hair`처럼 한 줄에 여러 태그를 쉼표로 나열해 동시에 삭제할 수 있다. 기존 한 줄 한 태그 방식도 유지하며, 따옴표 안의 쉼표와 단어 내부 apostrophe는 구분한다. 생성 요청과 토큰 미리보기가 사용하는 공통 삭제 처리에 적용한다. 같은 긍정/부정 계열 내 전체 태그 일치 삭제, 조건 평가 후 삭제, 비활성 입력 제외 등 기존 규칙을 유지한다.
- 저장된 프롬프트·프리셋 원본, 저장 구조와 키, migration은 변경하지 않는다. 입력 중 편집 범위와 생성 시 임시 변환만 처리한다.
- 검증: 조건 검색·실제 삽입 함수, 커서 중간·CRLF·AND/OR·기존 랜덤/일반/가중치 자동완성, 다중 삭제의 V4.5/V5·공백 모드·메인/캐릭터·긍정/부정 및 원본 보존 검사를 통과했다. 격리 브라우저의 실제 편집기·내장 태그 DB로 Tab/마우스 선택 및 Undo/Redo도 확인했다. production build는 통과했으며 lint는 기존 ESLint 설정 파일 누락으로 실패했다. 실제 설치판 및 NovelAI 유료 생성은 실행하지 않았다.

## Windows 자동 숨김 작업표시줄 보정 내장

- 앱을 켜면 별도 보조 프로그램 없이 기본 창의 상태에 맞춰 자동 동작한다. 기본 창이 활성화되어 모니터를 덮을 때 Windows에 전체화면 표식을 전달하며, 최대화 버튼을 사용한 상태도 포함한다. 일반 크기·화면 분할·최소화·숨김·다른 앱 전환·종료 때 명시적 표식을 해제한다.
- 창 크기나 항상 위 설정, 시스템 작업표시줄 설정은 변경하지 않는다. 표식 해제 후에는 Windows 자체 전체화면 감지 정책이 적용된다. 최대화에서 관찰된 작은 여백만 물리 픽셀 기준으로 허용한다.
- 창과 Shell의 상태 변경 이벤트를 사용해 재적용하며 외부 프로세스 감시나 주기적 polling은 추가하지 않는다. 사용자 설정·이미지·저장 구조·migration 변경은 없다.
- 외부 보조 프로그램을 `--stop`으로 정상 종료한 뒤 별도 식별자의 실제 Tauri 테스트 앱에서 검증했다. 1920×1080/96 DPI 최대화의 1920×1079 클라이언트에서 하단 3지점이 모두 NAIS2를 반환했다. 일반 창·화면 분할·정확한 화면 덮음·일반 창의 1px 부족·최소화/복원·숨김/재표시·다른 앱 전환·종료의 적용/해제 호출 성공을 임시 계측으로 확인했다. Shell 재생성 알림은 실제 Explorer 재시작 대신 메시지 전달로 확인했다.
- 다중 모니터·DPI 설정 변경의 실제 장비 검증과 화면 캡처를 통한 육안 검증은 하지 못했다. 음수 모니터 좌표·물리 픽셀 허용 범위는 native 단위 검사로 확인한다. 기존 설치판은 유지한다.
- 최종 검사: Rust 단위 테스트 15개, Windows native 빌드, production build, 설치 경로 연속성 검사 통과. lint는 기존 ESLint 설정 파일 누락으로 실패했다. 임시 계측은 제거했다.
