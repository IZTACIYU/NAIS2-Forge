# v1.15.0 개발 로그

## 그림체 프리셋 초기화 결함 수정

- 앱 시작이나 새로고침 중 기존 그림체 프리셋 목록이 기본 프리셋 하나로 덮어써질 수 있던 결함을 수정했다. 초기 함수 등록 자체가 저장을 발생시키던 경로를 제거하고, 생성 설정과 프리셋이 모두 로드되기 전에는 자동 동기화가 저장을 예약하거나 실행하지 않게 했다. 프리셋 전환·편집 후 자동 저장과 기존 지연 시간은 유지한다.
- 사용자 지시 범위는 다음 업데이트에서의 재발 방지다. 기존 저장 키·DB/backend·schema·직렬화·hydration 기본값·migration은 변경하지 않는다. 프리셋 ID·순서·프롬프트·설정·선택과 추가 필드를 보존하며 초기 로딩만으로 프리셋을 다시 저장하지 않는다. 설치판의 실제 DB를 열거나 수정·복구하지 않았으며, 이미 덮어써진 목록 복구는 별도 세션에서 진행한다.
- 격리된 비동기 저장소에서 실제 프리셋·생성 store와 Zustand middleware를 실행해 검증했다. 양쪽 로드 순서, 저장소 재생성을 통한 반복 새로고침 상황, 6개 전체 레코드와 알 수 없는 필드 보존, 프리셋 전환·편집 동기화, 로드 중 예약된 저장 및 읽기 실패의 덮어쓰기 차단을 통과했다. 통과 검사를 반복하거나 설치판 재시작·전체 저장 키·조각·이미지 전수 검사를 하지 않았다.
- production build와 관련 회귀 검사는 각 1회 통과했다. lint는 1회 실행했으나 기존 ESLint 설정 파일 누락으로 실패했다. 씬 이동 시 깜빡임 자체의 원인은 확인하지 않았고 이번 결함과 같다고 단정하지 않는다.
- 실제 앱 버전은 1.14.0으로 유지한다. 릴리즈·태그·워크플로 실행은 진행하지 않았다. 저장 형식 변경이나 데이터 migration이 없어 새 버전을 위한 변환/정리 작업은 필요하지 않으며, 구버전에는 같은 초기화 결함이 남아 있으므로 단순 다운그레이드를 데이터 보존책으로 보지 않는다.

## 콘솔로 켜는 씬 스택과 캐릭터별 ZIP 백업

- 입력 포커스가 없는 상태에서 `Ctrl+Shift+Backquote`로 여는 내부 콘솔을 추가했다. `scene.stack on/off`, `scene.czip on/off` 네 가지 명령만 허용하며 임의 JavaScript나 시스템 명령은 실행하지 않는다. IME 조합·키 반복·이미 처리된 키·다른 모달에서는 실행하지 않는다. 일반 설정 화면에는 노출하지 않는다.
- 씬 스택은 이미지에 기록된 Forge 캐릭터 표시 이름을 기준으로 계산한다. 내부 구분 해시와 변형 번호는 표시 이름에서 제외하며, 프롬프트 문자열이나 현재 캐릭터 목록으로 추측하지 않는다. 메타데이터를 읽지 못하거나 이름이 없으면 개별 이미지로 남긴다. 스택을 눌러 내부 이미지를 열고 돌아올 수 있으며, 대표 이미지는 기존의 최신 즐겨찾기 우선 규칙을 사용한다. 편집 모드는 기존 평면 목록을 유지한다.
- 켜진 경우 기존 `.zip` 아래에 `C.zip`을 표시한다. 현재 프리셋의 상위 4개 씬에 등록된 이미지에서 캐릭터 목록을 찾고 검색·전체 선택·선택 해제를 제공한다. 내보내기는 전체 씬에서 선택한 캐릭터마다 씬당 대표 이미지 한 장을 모아 순차적으로 ZIP을 만든다. 누락 씬은 건너뛰고, 선택한 이름이 여러 개 겹치는 이미지·분류 불가·읽기 실패는 집계한다. 스택 모드에서는 스택의 최상단 이미지를 사용한다.
- 출력 폴더를 한 번 지정하고 캐릭터 이름으로 ZIP을 저장한다. 기존 ZIP과 작업 중 임시 파일 이름을 피하고 중복 이름에는 번호를 붙인다. 일반 씬 ZIP과 파일 이름 생성·PNG/WebP/JPEG 변환·진행률·native ZIP 경로를 공유한다. 예상하지 못한 내보내기 실패는 이후 캐릭터 작업을 중단하며 이미 완료된 ZIP은 유지한다.
- **데이터 변경 승인:** 구현 전 사용자가 두 기능의 재실행 후 ON/OFF 유지에 동의했다. 기존 `nais2-forge-settings`에 기본값 false인 두 boolean만 추가한다. 기존 설정 값과 추가 필드를 보존하며 초기화만으로 저장하지 않는다. 저장 키·backend·migration·씬/라이브러리 구조·이미지 배열·이미지 파일과 폴더는 변경하지 않는다. 스택과 체크 목록은 메모리에서만 계산한다. 별도 migration이나 원본 삭제는 없고, 기능 OFF 또는 코드 rollback 시 원래 평면 표시로 돌아간다.
- 실제 Zustand middleware와 격리된 비동기 저장소에서 기본값 저장 없음·설정 재로드 유지·기존 필드 보존을 검증했다. 합성 Forge PNG로 이름 판독·상위 4개 씬 제한·즐겨찾기 대표·불명 이미지 분리·중복 이름·누락 씬을 확인했고, 모의 native 경계에서 3개 이미지 형식의 순차 내보내기와 기존 파일 이름 회피를 확인했다. 격리된 Edge에서 실제 콘솔·입력 포커스 차단·스택 열기/복귀·캐릭터 선택창과 3개 언어의 좁은/일반 폭을 확인했다. 설치판 데이터에 접근하거나 실제 native ZIP/이미지 변환 파일을 생성하는 검사는 하지 않았다.
- production build를 통과했다. lint는 기존 ESLint 설정 파일 누락으로 실행에 실패했다. 통과한 기능 검사를 반복하지 않았고 설치판을 실행하지 않았다.
- 새 사용자 기능 추가로 기존 v1.14.1 유지보수 로그를 v1.15.0에 합쳤다. 실제 앱 버전은 1.14.0이며 릴리즈는 하지 않는다.
